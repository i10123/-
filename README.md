### Проблема: Нужно больше креативности
```text
[Твой запрос]
Требования:
Избегай очевидных/стандартных решений
Предложи как минимум 3 нестандартных подхода
Вдохновляйся примерами из других индустрий
Будь креативным, даже если идеи кажутся рискованными
```
### 3 эксперта
```text
Представьте, что три разных эксперта отвечают на этот вопрос.
Каждый из экспертов запишет 1 шаг своего мышления, а затем поделятся им с группой.
Затем все эксперты переходят к следующему шагу и т.д.
Если кто-то из экспертов понимает, что он ошибается на каком-то шаге, он выходит.
Вопрос в том, что [ваша задача]
```
